One funny single-line excuse a developer gives when code breaks in production — the most worn excuse of all time, turned on its head: "it works on my machine" is only funny until you realise the deploy shipped the developer's own machine as production.

The program writes the excuse to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Developer Excuses" bounty.

## Run it

```sh
node main.ts
```

It writes one line to `/output/entry.txt` (73 characters, single line, UTF-8) and exits. Deterministic: the same text on every run.
